Bootstrap terms

术语 替代标签 定义
Node (未翻译) — One file, or one part of a file addressable by an IRI fragment, named by an IRI. (未翻译)
Reference (未翻译) — A Node’s naming of another Node by its IRI. (未翻译)
Node Schema (未翻译) — A schema a Node can be checked against: a JSON Schema, or a published external schema such as BPMN’s. (未翻译)
Node Kind (未翻译) — A name paired with a Node Schema. (未翻译)
Subkind (未翻译) — A Node Kind whose Node Schema requires everything another Node Kind’s does, so every Node that satisfies it satisfies the other too. (未翻译)
Node Instance (未翻译) — A Node that names its Node Kind, in $schema or front matter, and satisfies that kind’s Node Schema. (未翻译)
Graph Typology (未翻译) — A named set of Node Kinds. (未翻译)
Declaration (未翻译) — A JSON document, <name>.json, that gives a name and lists directory entries and file entries. (未翻译)
Extension (未翻译) — A field of a Declaration, or of one of its entries, that is not defined here. A reader that does not recognise the field ignores it, and the rest of the Declaration keeps its meaning. (未翻译)
Subgraph (未翻译) — A directory entry of a Declaration: an id, a directory, and the Graph Typologies its Node Instances’ kinds belong to. (未翻译)
Asset (未翻译) — A file entry of a Declaration: one file about the repository itself, whose role field says what it is for. (未翻译)
Knowledge Graph (未翻译) — The Node Schemas, Node Instances and Assets one Declaration lists, as of one version of the repository. Published as JSON-LD, the statements of each Subgraph’s Node Instances form one named graph. (未翻译)
Dependency (未翻译) — A Declaration’s needs entry naming another Knowledge Graph. References may point from this graph’s Node Instances into the named one, never back. (未翻译)
Content (未翻译) — Node Instances that describe the subject matter of a Knowledge Graph, such as records, documents, catalogues and their terms, rather than how to work with it. (未翻译)
Task (未翻译) — A unit of work, stated by what it needs to begin and what it produces. (未翻译)
Actor (未翻译) — A person, an agent or a program that can carry out Tasks. (未翻译)
Skill (未翻译) — A Node Instance stating a responsibility an Actor carries out to complete a Task: as natural-language instructions to follow, as a contract to be tested against, or both. (未翻译)
Role (未翻译) — A Node Instance naming a part an Actor takes on to carry out Tasks, and listing the Skills that part needs. (未翻译)
Process Node (未翻译) — A BPMN flow node: an activity (a task or call activity), a gateway, or an event. (未翻译)
Sequence Flow (未翻译) — A directed connection in a BPMN process from one Process Node to the next. (未翻译)
Process (未翻译) — A Node Instance holding a BPMN process that coordinates Tasks: its Process Nodes, joined by Sequence Flows, sit in lanes that each name a Role. (未翻译)
Harness (未翻译) — A Knowledge Graph whose Subgraphs hold Skills, Roles or Processes: what an Actor uses to work with a Knowledge Graph, including itself. (未翻译)

Folio Assistant platform terms (cat-harness)

术语 替代标签 定义
associated harness (未翻译) — A harness this one knows by name, site and repository, and never loads, builds or copies. The fourth relation beside depends (needs), references (remoteGraphs) and utilizes (dependencies). (未翻译)
policy (未翻译) — Which Actor may do which action, and where, written as W3C ODRL 2.2 permission and prohibition rules scoped by Process, Task and Role. (未翻译)
permission (未翻译) — One ODRL rule allowing an assignee an action, optionally on a target and within constraints. A permission to a broader action permits every action included in it. (未翻译)
task run (未翻译) — One performance of a BPMN task by an Actor in a Role under a policy, recorded as a W3C PROV-O activity whose plan is the task. (未翻译)
actor (未翻译) — A concrete participant, human, agentic or mechanical, that persists across every process and takes on roles. Which login is which actor is the data store’s to know. (未翻译)
role (未翻译) — The swimlane: a persona an actor takes on because of the lane it is acting in, carrying the skills that lane’s activities need. (未翻译)
user story (未翻译) — What a reader acting in a Role is trying to do, told as that role: as a , I want , so that . The story points at its role; the role names no story. _(未翻译)_
test run (未翻译) — One measurement of a Skill: which skill it tests, the cases it exercised, and a hash of the data and a hash of the process that produced the result, so a third party can redo it. Its cases are checked against the skill’s input and output contracts. (未翻译)
voice (未翻译) — A named set of writing rules for prose, active in the roles and processes it names. The voice points at the role it is written for; the role names no voice. (未翻译)
external schema (未翻译) — A record of a specification the platform depends on but does not hold: which authority publishes it, which version is conformed to, and the operative terms used from it. (未翻译)
KG QA report (未翻译) — A committed QA sidecar recording, for one knowledge-graph subject such as a process, role or skill, which of its references fail to resolve under each audit criterion. (未翻译)
todo (未翻译) — One person’s outstanding work, as a content node the folio owns, tagged with the roles, processes and tasks it concerns. Not the agent work plan, which is beans. (未翻译)
bean (未翻译) — One item of the agent work plan, held by the beans CLI in the committed beans/ store, with a status, a parent and the beans it blocks. (未翻译)
JSON Schema (未翻译) — A JSON document that describes the shape of other JSON documents. In the platform, a node schema and a skill’s input and output contracts are each a JSON Schema file. (未翻译)

public health (未翻译) public health guideline (未翻译) A guideline whose recommendations address the health of populations rather than of an individual patient: prevention, health promotion, immunization and screening programmes, surveillance, and policy or environmental measures. (未翻译)
health system strengthening (未翻译) health systems strengthening (未翻译); HSS (未翻译) A guideline whose recommendations address how the health system itself is organised and resourced — service delivery, health workforce, health information systems, access to medical products, financing, and leadership and governance — rather than a particular condition or population intervention. (未翻译)
