public-comments

https://litlfred.github.io/folio-assistant-core/v0/ns/graphTypology/public-comments

A public-comment record — one `public-comment/1.0.0` JSON per comment under `comments/`, one `changeset/1.0.0` JSON per change-set under `changesets/`, and one `review-log/1.0.0` JSON per review log under `logs/`, beside that log's workbook (`logs/<id>.xlsx`). Written by the public-comment tool as comments are triaged and change-sets agreed, and by the review-log archive each night the log changed.
