المصطلحات المحرَّرة

Bootstrap terms

المصطلح تسميات بديلة التعريف
Node (غير مترجَم) — One file, or one part of a file addressable by an IRI fragment, named by an IRI. (غير مترجَم)
Reference (غير مترجَم) — A Node’s naming of another Node by its IRI. (غير مترجَم)
Node Schema (غير مترجَم) — A schema a Node can be checked against: a JSON Schema, or a published external schema such as BPMN’s. (غير مترجَم)
Node Kind (غير مترجَم) — A name paired with a Node Schema. (غير مترجَم)
Subkind (غير مترجَم) — A Node Kind whose Node Schema requires everything another Node Kind’s does, so every Node that satisfies it satisfies the other too. (غير مترجَم)
Node Instance (غير مترجَم) — A Node that names its Node Kind, in $schema or front matter, and satisfies that kind’s Node Schema. (غير مترجَم)
Graph Typology (غير مترجَم) — A named set of Node Kinds. (غير مترجَم)
Declaration (غير مترجَم) — A JSON document, <name>.json, that gives a name and lists directory entries and file entries. (غير مترجَم)
Extension (غير مترجَم) — A field of a Declaration, or of one of its entries, that is not defined here. A reader that does not recognise the field ignores it, and the rest of the Declaration keeps its meaning. (غير مترجَم)
Subgraph (غير مترجَم) — A directory entry of a Declaration: an id, a directory, and the Graph Typologies its Node Instances’ kinds belong to. (غير مترجَم)
Asset (غير مترجَم) — A file entry of a Declaration: one file about the repository itself, whose role field says what it is for. (غير مترجَم)
Knowledge Graph (غير مترجَم) — The Node Schemas, Node Instances and Assets one Declaration lists, as of one version of the repository. Published as JSON-LD, the statements of each Subgraph’s Node Instances form one named graph. (غير مترجَم)
Dependency (غير مترجَم) — A Declaration’s needs entry naming another Knowledge Graph. References may point from this graph’s Node Instances into the named one, never back. (غير مترجَم)
Content (غير مترجَم) — Node Instances that describe the subject matter of a Knowledge Graph, such as records, documents, catalogues and their terms, rather than how to work with it. (غير مترجَم)
Task (غير مترجَم) — A unit of work, stated by what it needs to begin and what it produces. (غير مترجَم)
Actor (غير مترجَم) — A person, an agent or a program that can carry out Tasks. (غير مترجَم)
Skill (غير مترجَم) — A Node Instance stating a responsibility an Actor carries out to complete a Task: as natural-language instructions to follow, as a contract to be tested against, or both. (غير مترجَم)
Role (غير مترجَم) — A Node Instance naming a part an Actor takes on to carry out Tasks, and listing the Skills that part needs. (غير مترجَم)
Process Node (غير مترجَم) — A BPMN flow node: an activity (a task or call activity), a gateway, or an event. (غير مترجَم)
Sequence Flow (غير مترجَم) — A directed connection in a BPMN process from one Process Node to the next. (غير مترجَم)
Process (غير مترجَم) — A Node Instance holding a BPMN process that coordinates Tasks: its Process Nodes, joined by Sequence Flows, sit in lanes that each name a Role. (غير مترجَم)
Harness (غير مترجَم) — A Knowledge Graph whose Subgraphs hold Skills, Roles or Processes: what an Actor uses to work with a Knowledge Graph, including itself. (غير مترجَم)

Folio Assistant platform terms (cat-harness)

المصطلح تسميات بديلة التعريف
associated harness (غير مترجَم) — A harness this one knows by name, site and repository, and never loads, builds or copies. The fourth relation beside depends (needs), references (remoteGraphs) and utilizes (dependencies). (غير مترجَم)
policy (غير مترجَم) — Which Actor may do which action, and where, written as W3C ODRL 2.2 permission and prohibition rules scoped by Process, Task and Role. (غير مترجَم)
permission (غير مترجَم) — One ODRL rule allowing an assignee an action, optionally on a target and within constraints. A permission to a broader action permits every action included in it. (غير مترجَم)
task run (غير مترجَم) — One performance of a BPMN task by an Actor in a Role under a policy, recorded as a W3C PROV-O activity whose plan is the task. (غير مترجَم)
actor (غير مترجَم) — A concrete participant, human, agentic or mechanical, that persists across every process and takes on roles. Which login is which actor is the data store’s to know. (غير مترجَم)
role (غير مترجَم) — The swimlane: a persona an actor takes on because of the lane it is acting in, carrying the skills that lane’s activities need. (غير مترجَم)
user story (غير مترجَم) — What a reader acting in a Role is trying to do, told as that role: as a , I want , so that . The story points at its role; the role names no story. _(غير مترجَم)_
test run (غير مترجَم) — One measurement of a Skill: which skill it tests, the cases it exercised, and a hash of the data and a hash of the process that produced the result, so a third party can redo it. Its cases are checked against the skill’s input and output contracts. (غير مترجَم)
voice (غير مترجَم) — A named set of writing rules for prose, active in the roles and processes it names. The voice points at the role it is written for; the role names no voice. (غير مترجَم)
external schema (غير مترجَم) — A record of a specification the platform depends on but does not hold: which authority publishes it, which version is conformed to, and the operative terms used from it. (غير مترجَم)
KG QA report (غير مترجَم) — A committed QA sidecar recording, for one knowledge-graph subject such as a process, role or skill, which of its references fail to resolve under each audit criterion. (غير مترجَم)
todo (غير مترجَم) — One person’s outstanding work, as a content node the folio owns, tagged with the roles, processes and tasks it concerns. Not the agent work plan, which is beans. (غير مترجَم)
bean (غير مترجَم) — One item of the agent work plan, held by the beans CLI in the committed beans/ store, with a status, a parent and the beans it blocks. (غير مترجَم)
JSON Schema (غير مترجَم) — A JSON document that describes the shape of other JSON documents. In the platform, a node schema and a skill’s input and output contracts are each a JSON Schema file. (غير مترجَم)

Guideline domain

المصطلح تسميات بديلة التعريف
clinical (غير مترجَم) clinical guideline (غير مترجَم); clinical health (غير مترجَم) A guideline whose recommendations address the care of individual patients by health workers: assessment, diagnosis, treatment and management of a condition in a person. (غير مترجَم)
public health (غير مترجَم) public health guideline (غير مترجَم) A guideline whose recommendations address the health of populations rather than of an individual patient: prevention, health promotion, immunization and screening programmes, surveillance, and policy or environmental measures. (غير مترجَم)
health system strengthening (غير مترجَم) health systems strengthening (غير مترجَم); HSS (غير مترجَم) A guideline whose recommendations address how the health system itself is organised and resourced — service delivery, health workforce, health information systems, access to medical products, financing, and leadership and governance — rather than a particular condition or population intervention. (غير مترجَم)
